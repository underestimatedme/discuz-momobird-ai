# MomoBird AI for Discuz!

把 Discuz! 论坛里游客能看到的主帖同步到 MomoBird 控制台的项目里，让这些帖子可以在「问答调试」和网站问答助手里被提问、被引用；每个主帖带上所在版块作为分类，读者在版块页和帖子页提问时，问答助手只用这个版块的内容回答。也可以把问答助手挂到论坛每个页面，并在帖子页一楼下方播放 AI 播客。

本插件属于 MomoBird 专业版功能。创建第一个项目时自动开始 14 天试用；企业空间按企业套餐。

## 功能

- 同步游客能读到的主帖（每个主题的第一帖），每个主题在项目里是一篇文档，由服务端统一切块和索引。
- 发主题、编辑主帖、追加内容、发布草稿、删除、移进回收站、从回收站恢复，以及前台管理（移动、关闭、打开、审核通过、删除）之后自动同步：符合条件的推送，不符合（或已经不存在）的从 MomoBird 撤下。
- 发帖不等待 MomoBird：钩子里只往插件自己的表里记一笔，不发网络请求；页面返回后（PHP-FPM）或由 5 分钟一次的定时任务推送。MomoBird 不可用或很慢时，发帖照常完成，速度不受影响。
- 后台改版块权限、改版块名称、关闭论坛这类没有钩子的变化，由每 5 分钟一次的设置比对发现；每天按主题编号分批扫描一轮，兜住其余漏掉的变化。
- 推送失败的主题每小时自动重试，最多 5 次；之后可以在后台点「重试失败项」。
- 后台「立即全量同步」，并撤下论坛里已经不存在或不该再同步的主题（有清理保护）。
- 可选：在前台显示 MomoBird 问答助手；在帖子页显示播客播放器。

回帖、门户文章、家园日志、群组里的帖子、附件不会同步。

## 环境要求

- Discuz! X3.5 或 X5.0，**UTF-8 编码**的站点（GBK / BIG5 站点后台只显示「本插件只支持 UTF-8 编码的论坛」，不做任何同步）
- PHP 7.4 或更高版本（X5.0 需要 PHP 8）
- 论坛服务器可以访问 `https://api.valley.atlaspaces.com`
- Base URL 必须是公网 HTTPS 地址：Discuz! 自己的网络层会拦截内网地址和 80、443 以外的端口

## 安装

1. 在 MomoBird 控制台（https://momobird.atlaspaces.com）打开或新建一个项目，进入「知识库 → 连接博客 → 博客 / 论坛」，平台选 **Discuz!**，站点地址填论坛的访问地址（与 Discuz! 后台「全局 → 站点信息」里的站点 URL 一致，例如 `https://bbs.example.com`）。
2. 复制页面上显示的**连接密钥**（以 `mbk_` 开头，只显示这一次），并下载插件包 `discuz-momobird-ai-0.1.0.zip`（也可以直接下载：https://momobird.atlaspaces.com/downloads/discuz-momobird-ai-0.1.0.zip）。
3. 解压后把 `momobird_ai` 文件夹上传到论坛的 `source/plugin/` 目录（Discuz! 没有「上传插件包」按钮）。
4. 在 Discuz! 后台「应用 → 插件」里找到 MomoBird AI，点「安装」，再点「启用」。
5. 打开插件的「MomoBird AI」页面，填写连接密钥并保存，点「测试连接」，确认项目名称和套餐，然后点「立即全量同步」。

安装会创建两张表：`{表前缀}momobird_ai_post`（每个主题的同步状态、内容摘要和脱敏的错误，不存正文）和 `{表前缀}momobird_ai_kv`（设置、密钥、对账进度和状态缓存），并添加定时任务「MomoBird AI 同步」。

## 设置

设置都在插件自带的「MomoBird AI」页面里，不使用 Discuz! 的插件变量（那个自动生成的设置页会把值原样显示在输入框里）。

| 设置 | 说明 |
| --- | --- |
| 连接密钥 | 控制台生成的 `mbk_` 密钥。只写不读：保存后页面只显示前 8 个字符，留空保存会保留已保存的密钥 |
| Base URL | 默认 `https://api.valley.atlaspaces.com`，通常不需要修改；必须是 HTTPS |
| 请求超时 | 2–30 秒，默认 10 秒 |
| 论坛地址 | 帖子链接的前缀。留空时用 Discuz! 后台「全局 → 站点信息」里的站点 URL；那里还是安装时的 `https://www.discuz.vip/` 时必须填写 |
| 同步哪些版块 | 默认「全部游客可见的版块」；也可以只选一部分。游客看不到的版块列出来但不能选，并写明原因 |
| 显示问答助手 | 默认关闭。打开后在每个页面底部加载 MomoBird 助手 |
| 问答助手位置 | 右下角（默认）或左下角 |
| 帖子页显示播客播放器 | 默认打开。主题生成过播客时一楼下方出现播放器，没有播客的主题不显示任何内容 |
| 播放器显示文字稿 | 默认关闭 |

帖子链接不取访问者请求里的域名（定时任务由随便哪个访客触发，域名不可靠），一律以「论坛地址」开头。开启了伪静态（`forum_viewthread` 规则）时用伪静态地址，例如 `thread-12-1-1.html`。

## 同步规则

一个主题必须**游客能读到**，并且所在版块在「同步哪些版块」里，才会同步。判断全部在服务端按数据库字段做：

- **主题**：不在回收站、不是待审核或审核被忽略、不是草稿、不是「已移动」留下的跳转帖；阅读权限不高于游客组的阅读权限；不是付费主题；不是群组帖。
- **版块**：普通版块或子版块（分区不放帖子）；没有隐藏；没有访问密码、积分公式限制、版块售价，不是跳转链接版块；浏览权限为空（且游客可以访问论坛）或浏览权限里有游客组。
- **主帖**：没有被屏蔽；论坛设置了屏蔽被禁言用户的帖子时，作者没有被禁言；正文没有 `[password]`（整帖加密码时游客看到的是空白）。
- **站点**：游客组允许访问、论坛没有关闭。论坛关闭期间不推送也不撤下。
- **只同步主帖**：回帖不同步，回帖也不会触发推送。
- **隐藏内容去掉**：插件自己把正文转成纯文本，不调用 Discuz! 的 `discuzcode()`（它按当前访问者计算隐藏内容，在定时任务里会算错）。`[hide]`、`[hide=10]`、`[hide=d30,50]` 这类回复、积分、天数可见的段落整段去掉；`[quote]` 引用、附件、图片、音视频、`[payto]`、投票和活动等特殊主题数据也去掉；链接只留文字，表格和代码留文字。X5 新编辑器发的帖子转换它的 JSON 内容（段落、标题、列表、引用、代码保留文字，图片、视频、音频、附件块去掉），标题层级用 Markdown 的 `#` 表示。
- **空主帖**：转换后正文为空的主题跳过，不算失败；之前同步过的会先撤下。

别的插件提供的隐藏语法（例如「回复可见」增强插件）、直接改数据库的插件，本插件识别不了；这类版块请在「同步哪些版块」里取消。

## 版块分类和问答助手

- 每个主帖的分类是它所在的**顶层版块**的名称：子版块里的帖子用上级版块名，这样问「汽车版」时也会用到它下面「新能源」子版里的帖子。
- 版块名去掉 HTML 和多余空白，最长 64 个字。两个顶层版块名字相同（不同分区下都叫「综合讨论」很常见）时，两个都改成「分区名 / 版块名」，还相同再加「 #版块编号」。
- 控制台知识页可以按版块筛选。打开问答助手后，在同步范围内的版块页和帖子页，助手只用这个版块的内容回答；首页等其他页面用全部内容。
- 改版块名称、改分区后，下一次定时任务发现设置变了，把这些版块的主题整批重新推送，分类跟着变。

## 什么时候同步

- **发帖、编辑、删除、前台管理之后**：钩子把主题编号记进同步表。使用 PHP-FPM 的主机在页面返回给用户之后立刻处理；其他主机（例如 Apache 的 mod_php）由下一次定时任务处理。
- **定时任务每 5 分钟一次**：处理还没推送的、到时间重试的；比对设置（版块的类型、上级、状态、名称、浏览权限、访问密码、积分公式、售价、跳转链接，游客组的访问和阅读权限，论坛是否关闭，插件的版块选择），有变化就把涉及的版块的主题重新判断；再继续扫描一段主题（每次最多 20 秒，从新到旧，每次读 1000 行，大约一天扫完一轮），一轮扫完后撤下 MomoBird 上有、论坛里已不该同步的主题。
- **Discuz! 的定时任务靠访问触发**：没有人访问论坛时定时任务不会运行。访问量很小的论坛，请在服务器上加一个每 5 分钟访问一次论坛首页的系统定时任务，例如：

  ```bash
  */5 * * * * curl -s -o /dev/null https://bbs.example.com/forum.php
  ```

  使用 PHP-FPM 的主机，定时任务在页面返回给访客之后运行，每次最多 20 秒；没有 PHP-FPM 的主机（例如 Apache 的 mod_php），定时任务在触发它的那次访问的页面输出之后运行，每次只做约 5 秒（再加最多一次请求的超时），一轮扫描要多跑几次。MomoBird 连不上时，连接状态每 15 分钟才重试一次，不会每次都等超时。访问量小的论坛和没有 PHP-FPM 的主机，都建议加上面的系统定时任务，让它来触发定时任务，读者就不会碰上这次等待。
- **只能等扫描的变化**：后台审核、后台批量管理主题、在后台把单个主题改成付费、到期自动关闭等没有钩子、又不是版块设置的变化，最长等扫描这一轮扫到它（一天之内）。存档到分表里的主题也会被扫描。
- **没有钩子的删除**：合并主题时被并掉的主题、别的插件或工具直接从数据库删掉的主题，扫描到那一段（或每轮对账）时发现它已经不存在，就从 MomoBird 撤下。一次发现超过 10 篇时可能是读取论坛数据出错，清理保护会先暂停，后台页面写明篇数，点「确认撤下」后执行。
- **MomoBird 上缺了的主题**：每轮对账（每天一轮，以及每次「立即全量同步」的最后）对照 MomoBird 上的列表，已经同步过、但 MomoBird 上没有的主题（例如在控制台删掉了）会重新推送。换了连接密钥、连到另一个来源时，插件发现来源变了，会把论坛里的主题全部重新推送到新来源。
- **立即全量同步**：后台页面由浏览器分批推送（每批 20 篇，从最新的主题往旧的推），最后对照 MomoBird 上的列表撤下不该再有的主题。请在同步过程中保持页面打开；中途关掉也没关系，定时任务会接着补。
- **清理保护**：本地一篇都不该同步，或者要撤下的超过 10 篇且超过 MomoBird 上总数的一半时，自动撤下会暂停，后台页面显示原因和「确认撤下」按钮，确认后才执行。取消勾选版块导致的撤下也走这条保护。

## 额度提示

全量同步和扫描都从最新的主题往旧的推，所以套餐的每月向量化额度先用在最新的内容上。后台页面在第一次全量同步前显示「本地应同步 N 篇」，同步后显示 MomoBird 上的篇数和可检索篇数；两者相差超过 20% 时提示「部分主题还没有索引，可能是本月额度已用完，请到控制台『用量』查看」，并建议用「同步哪些版块」缩小范围。插件按本地内容摘要去重，内容没变的主题不会重复推送，额度用完时也不会每天把同一批主题反复推送。

## 前台问答助手与播客

- 打开「显示问答助手」后，第一次全量同步成功时，如果项目的网站接入还没发布过，插件自动发布一次，并把论坛地址加进控制台「网站接入 → 允许网站」；网站接入以前已经发布过的，插件不会改动它，请自己把论坛地址加进「允许网站」。在控制台关闭或撤销过网站接入的，插件不会再自动打开。
- 读者访问页面时插件只读本地缓存，不请求 MomoBird；定时任务每小时刷新一次状态。项目下线、助手关闭、来源停用、套餐到期时不输出助手脚本。
- 播客在 MomoBird 控制台生成；插件只在同步范围内的帖子页一楼下方放一个占位元素，并加载 `https://momobird.atlaspaces.com/widget/podcast.v1.js`。
- 这两段输出只带主题编号、项目公开 ID 和来源 ID，不带连接密钥。

## 专业版与试用

- 试用或专业版到期后（402），插件停止推送，后台页面显示「套餐已到期」；**撤下照常执行**，移进回收站、删除、改成游客不可见的主题仍会从 MomoBird 撤下；前台助手隐藏。
- 因到期没推送的主题不进失败列表。开通或续费后，点「立即全量同步」或等下一轮扫描补齐。
- 开通或续费：在 MomoBird 控制台点顶栏的套餐，输入兑换码。

## 停用与卸载

- 停用插件（「应用 → 插件」里点「关闭」）：钩子和定时任务不再运行，不删除 MomoBird 上的知识，也不删除本地同步表和设置，再次启用即可继续（停用期间的变化由设置比对和扫描补上）。
- 卸载插件：删除两张插件表（设置、密钥、同步状态一起删除）。MomoBird 上的知识需要在控制台删除对应来源。

## 故障排查

| 状态或现象 | 检查项 |
| --- | --- |
| 401 / 「连接密钥无效或已被撤销」 | 连接密钥缺失、复制错误、已被重新生成或吊销，或者控制台里的来源已被删除。保存新密钥后会立刻重新检查 |
| 402 `PLAN_REQUIRED` / 「套餐已到期」 | 试用或专业版已到期；新主题不会同步，撤下仍会生效。开通后点「立即全量同步」补齐 |
| 409 `SOURCE_DISABLED` / 「这个来源已在 MomoBird 控制台停用」 | 到控制台重新启用来源，再点「测试连接」 |
| 409 `WIDGET_NOT_READY` | 还没有任何主题完成索引，助手没能开启；下一次定时任务会自动再试 |
| 413 / `TOO_LARGE` | 单个主帖正文太大，记进失败列表；其他主题照常推送 |
| 「论坛地址和 MomoBird 来源的网站地址不一致」 | 两边必须同源（协议、域名、端口都一样，注意 `www` 和 http/https）。在插件设置里改「论坛地址」，或在 Discuz! 后台「全局 → 站点信息」改站点 URL；在这之前不推送，撤下照常 |
| 「无法连接 MomoBird」，Base URL 是内网地址或非标准端口 | Discuz! 的网络层会拦截内网地址和 80、443 以外的端口；Base URL 请保持默认的公网 HTTPS 地址 |
| 「无法连接 MomoBird」/ 超时 | 服务器无法访问 MomoBird，或超时设置过短 |
| 同步很慢、几小时都没跟上 | 定时任务靠访问触发，论坛没人访问时不运行；按上面「什么时候同步」加系统定时任务。没有 PHP-FPM 的主机，发帖后要等下一次定时任务，每次只做约 5 秒 |
| 「论坛里读不到 N 篇已经同步过的主题」 | 这些主题被删除了，或者读取论坛数据出错（例如分表无法访问）。确认确实删除后点「确认撤下」 |
| 知识源类型不是 discuz 的提示 | 填的是其他平台来源的密钥；能推送，但不会自动撤下。建议在控制台新建 Discuz! 来源换上它的密钥 |
| 失败列表里有主题 | 看错误码，修好后点「重试失败项」 |

## 开发

```bash
php tests/run.php                # 单元测试（不需要 Discuz!）
scripts/lint.sh                  # PHP 7.4 语法检查（docker）+ 本机 PHP 的弃用检查
scripts/integration.sh x35       # Docker 集成测试：Discuz! X3.5 + php:7.4-apache（mod_php）
scripts/integration.sh x5        # Docker 集成测试：Discuz! X5.0 + php:8.2-fpm + nginx
scripts/package.sh               # 生成 dist/discuz-momobird-ai-<版本>.zip
```

集成测试会拉取固定版本的 Discuz! 官方源码（gitee `Discuz/DiscuzX`：X3.5 标签 `v3.5-20260504`，X5.0 `MitFrame` 分支提交 `992ace3`），用安装程序的无界面模式装好论坛，装上插件，用 `dev/mock-connect.php`（connect API 的本地替身，另一个容器）代替 MomoBird，然后像浏览器一样发帖、编辑、管理，检查替身收到的推送和撤下。跑完删除所有容器和网络（`MB_IT_KEEP=1` 保留，便于排查）。脚本里的论坛管理员账号、数据库密码和假连接密钥都只是本地测试值。测试用的 Base URL 是替身的容器主机名，只在测试论坛的 `config_global.php` 里用 `$_config['momobird_ai']['http_hosts']` 放行。

`scripts/package.sh` 生成的 zip 顶层目录是 `momobird_ai/`，只包含插件文件，不含测试、开发文件和脚本，并检查里面没有连接密钥和测试凭据。

## 安全说明

- 所有 MomoBird 请求都从论坛服务端发出，开启 TLS 证书校验（Discuz! 默认不校验，插件自己的请求校验），不跟随跳转，并限制响应体大小。前台只输出问答助手和播客的公开 ID。
- 连接密钥只存在插件自己的表里，后台页面、前台页面、Discuz! 的后台操作日志、错误信息和同步表都不会出现密钥原文；错误信息里形似密钥的字符串一律抹掉。
- 后台页面只有能管理插件的管理员能打开，所有提交都校验 Discuz! 的 `formhash`。
- 前台管理钩子只接受登录的版主或管理员完成的操作；请求里不存在的主题编号不会写进同步表。
